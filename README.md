# US States Quiz

A 10-question quiz on US state maps and flags, built in code.org App Lab (JavaScript).

## How it works
- Pick a maps quiz or a flags quiz
- Choose the state name from a dropdown for each image
- Get a score out of 10 with feedback at the end
